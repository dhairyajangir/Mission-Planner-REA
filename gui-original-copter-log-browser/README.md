## Legend and recorded values

The legend displays **Min 584.09, Max 584.09, Mean 584.09**. In this file the first sample is 578.12 m and the remaining 390 samples are 584.09 m. Across all 391 points the minimum is 578.12 m, the maximum is 584.09 m and the mean rounds to 584.07 m. The initial point appears on the drawn line. The earlier component capture exposed the actual series, with the first UTC time at 05:22:17.800 on November 4, 2026. The earlier modified application also drew the rise. [Component points](../sitl-evidence/copter-log-gps-graph/points.csv) · [Component verification](../sitl-evidence/copter-log-gps-graph/verification.json) · [Earlier GUI trace](../Log-Workflow-Trace.md)

The pinned `ExtLibs/ZedGraph/ZedGraph/Line.cs` explains the difference for this sample. The drawing loop starts with `lastBad = true` (line 657). It accumulates the current Y value only inside the valid-segment branch (743–761), then draws between the previous and current coordinates. The first valid point establishes the previous point (830). The legend uses those drawing statistics (843). Here every segment ends at 584.09 m. This explains how the graph includes the starting altitude while its legend reports the same value for all three statistics.

The shipped ZedGraph DLL contains the same first-point branch and endpoint calculations in `Line.DrawCurve`. The graph and full-record calculation agree with that code path. This session recorded the rendered window rather than individual loop iterations. [Release IL excerpts](../gui-original-copter-log-legend/ZedGraph-DrawCurve-legend-IL.txt)

## Scope and replay

The 5,660,672-byte [input](../sitl-evidence/nonempty-log-probe/downloaded.bin) came from the archived simulator session. The new run opened it read-only using the ordinary application file dialog in a private Ubuntu-E namespace with loopback as its sole network interface, a temporary user profile and Xvfb. Mono 6.8.0.105 ran the original executable. All 1,317 release files matched the ZIP after exit. Two log files were created. The user's profile setting disabled release plugins for this session. Native Windows rendering and other logs or fields remain untested by this run. [Archive comparison](archive-comparison.json) · [Profile](initial-user-config.xml)
