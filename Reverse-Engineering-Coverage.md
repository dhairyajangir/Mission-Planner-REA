Separate Copter 4.7.2 SITL runs exercised both conversions between a legacy return point and closed triangle and a typed return point with three inclusion-polygon vertices. This simulator result is a compatibility hazard for a custom client that mixes old and typed fence operations; it does not establish behavior across builds or real hardware.

The original library started accelerometer calibration in disarmed Copter SITL and received repeated level-position requests. Two forced-armed simulator tests found that the library's full-accelerometer calibration call returned true before the vehicle's failed ACK and disarm notice. In a disposable source-built Copter SITL run, the original library set up signing with a public synthetic key, which the harness also placed into the vehicle state by reflection. Two standalone-client SITL runs compared signing behavior on virtual SERIAL0 and SERIAL1.
