# Original Geo Ref Images window

Mission Planner 1.3.83 opened the Geo Ref Images window from its Ctrl+F tools menu on 21 November 2026. The disconnected application logged `Open MissionPlanner.GeoRef.Georefimage Geo Ref Images`. The form opened with **CAM Message** selected and **Use AMSL Alt** checked. Selecting **Time offset** enabled the seconds-offset input and Estimate Offset button, and disabled the shutter-lag input. Both numeric fields displayed zero. [Application log](capture/release.log) · [Default view](capture/georef-visible.png) · [Time offset selected](capture/offset.png)

The form showed separate Browse Log and Browse Pictures controls, three synchronization modes, GPS2 and altitude options, and the Pre-process, Location Kml and GeoTag Images buttons. Both paths and the results pane were empty. The offline map displayed unavailable imagery and a host lookup error. The operator opened the tools menu from Help, clicked Geo ref images and resized the form for a clear capture before changing the mode. No file chooser, processing action or camera connection was used. The earlier synthetic JPEG study covers matching and writing at library level. [Tools menu](capture/tools.png) · [Control tree](capture/offset-tree.txt) · [Actions](capture/observation.log) · [JPEG study](../copter-photo-geotagging-study/TRACE.md)

The Linux/Mono guest used a private X display, temporary profile and isolated network namespace. The post-run archive comparison matched all 1,317 release files and recorded two additional application log paths. This establishes original GUI execution for the `mp-module:GeoRef` L3+gui row.
