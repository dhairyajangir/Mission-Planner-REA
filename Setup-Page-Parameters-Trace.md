# Setup-page parameter map trace

Scope: which parameter names Mission Planner 1.3.83's configuration pages (`GCSViews/ConfigurationView/*.cs`) mention, and how many of those names the pinned ArduPilot firmware snapshot declares. This is a **static text scan** of source files. No page was opened, no vehicle or simulator was connected and no parameter was read or written. It shows what the code names, not what the pages do.

## Method

- `research-tools/build-ardupilot-param-names.py` turns the snapshot's own generator output into `coverage/ardupilot-param-names.csv`: 6,925 names with a flag for each of ArduCopter (5,800 names), ArduPlane (5,872), Rover (5,539), ArduSub (5,477), AntennaTracker (3,684) and Blimp (3,158). The generator is `Tools/autotest/param_metadata/param_parse.py` in the snapshot (commit `72b238201f5ea3b556e3809b2ec704fcf701474a`), run in WSL with `--format json` and an existing Python environment that has `lxml`. It parses parameter declarations from the C++ source, so parameters created only at run time may be missing. Spot checks agree with the source: `COMPASS_PRIMARY` is absent from the generator output and the snapshot's `AP_Compass.cpp` has no `PRIMARY` entry; `RC1_MIN`, `BATT_MONITOR` and `FS_THR_ENABLE` are present.
- `research-tools/build-config-param-map.py` finds quoted upper-case names inside four call shapes and writes `coverage/config-page-params.csv` (903 rows) and `config-page-params-summary.md`. `setup-alias` rows come from `<control>.setup(...)`, where a page lists alternative names for different firmware versions. `read` rows come from `param["X"]`, `ContainsKey("X")` and array lookups, `write` rows from `setParam(...)`, and `get` rows from `GetParam(...)`. A name joined to another string with `+` (a runtime prefix or channel number) is marked `partial` and not checked. `--check` fails when the committed files are stale.

## Results

- 31 of the 65 page source files mention at least one name; 595 distinct names appear. 511 rows are names the snapshot declares, 365 are not, and 27 are joined to another string.
- 273 distinct names are not declared by the snapshot. Most are old aliases that the page lists next to a newer name, which is the intended use of the alias lists (323 `setup` calls; 105 list more than one name).
- **76 of the 323 alias lists have no name the snapshot declares.** In those controls every candidate name is absent, so against this firmware the control would find no parameter. By page: `ConfigArducopter` 26 of 71, `ConfigTradHeli` 14 of 47, `ConfigArduplane` 12 of 44, `ConfigArdurover` 5 of 31, `ConfigFailSafe` 5 of 17, `ConfigRadioInput` 4 of 8, `ConfigMount` 3 of 21, `ConfigAntennaTracker` 2 of 25, and one each in `ConfigAC_Fence`, `ConfigHWCAN`, `ConfigHWCompass`, `ConfigHWOptFlow` and `ConfigHWRangeFinder`. `ConfigHWCAN` and `ConfigHWRangeFinder` have a single control each and both are in the list.
- Examples where the snapshot declares a different name: the battery fail-safe controls name `FS_BATT_ENABLE`, `FS_BATT_VOLTAGE`, `FS_BATT_MAH` and `LOW_VOLT` while the snapshot has `BATT_FS_LOW_ACT` and related names; the range finder page names `RNGFND_TYPE` (snapshot: `RNGFND1_TYPE`); the optical flow page names `FLOW_ENABLE` (snapshot: `FLOW_TYPE`); the Copter fence page names `RTL_ALT` (snapshot: `RTL_ALT_M`); the primary-compass control names `COMPASS_PRIMARY`, which the snapshot does not have.
- Direct reads and writes (outside alias lists) that name undeclared parameters are concentrated in `ConfigHWesp8266` (49 rows), `ConfigHWOSD` (24 writes) and `ConfigHWCompass2` (10 reads).

## What this does and does not show

It does show the set of parameter names a replacement setup screen would need to know, with the firmware-version alias lists the original pages use, and which of them a current firmware snapshot no longer declares. It does not show how each page behaves, which names are used on a given vehicle, whether the 1.3.83 pages substitute newer names at run time by some route this scan cannot see, or anything about pages outside `ConfigurationView` or names set through designer properties. A name absent from the snapshot may still exist in firmware released before or after it. The generator's coverage was spot-checked, not proven complete.
