The guest used a new temporary profile and release extraction, a private loopback network and an isolated X display. The firmware window identified ArduCopter V4.8.0-dev (15a10bb4). The operator used the ordinary Connect dialog with TCP host 127.0.0.1 and port 5760. The release reported 1,431 received parameters out of 1,431. The recorder then opened SETUP and CONFIG. ## Verification

The final telemetry file contained 46 CRC-checked heartbeats from the simulated Copter. All reported disarmed. The samples bracketed both the hardware OSD and CONFIG captures. The recording contained zero outgoing PARAM_SET messages, and the post-run comparison matched all 1,317 release files. [Verification results](verification.json)

The result also reports outgoing MAVLink PARAM_SET messages in the captured session. It does not test a physical display or aircraft.
