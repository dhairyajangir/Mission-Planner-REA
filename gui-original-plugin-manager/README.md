# Original plugin manager in the disconnected release

Pressing **Ctrl+P** in Mission Planner 1.3.83 opened the separate **PluginManager** window. Its grid displayed **Plugin Name**, **Author**, **Version**, **FileName** and **Enabled**. The green, checked first row was **Grid**, **Michael Oborne**, **1.3.9384.38250**, **self**. Red, unchecked rows included `example-watchbutton.cs`, `example.cs` and `example10-canlogfile.cs`, each labelled **Not loaded**. The **Save & Close** and **Show Errors** buttons remained idle. A second capture twelve seconds later showed the same pixels. [Window](manager-open.png) · [Window tree](manager-tree.txt) · [Second capture](manager-settled.png)

The release metadata places **MissionPlanner.Controls.PluginUI** in `MissionPlanner.exe`. Its type definition includes `PopulateGridView`, `bSave_Click` and `UpdateDisabledPlugins`. The same EXE defines `MissionPlanner.Plugin.Plugin` and `MissionPlanner.Plugin.PluginLoader`. In the pinned source, `MainV2.cs` lines 4094–4096 dispatch Ctrl+P to `new PluginUI().Show()`. The form is defined in **Plugin/PluginUI.cs**, in the **MissionPlanner.Controls** namespace. This gives original GUI evidence for **mp-module:Plugin**. The separate **Plugins/** source directory contains individual samples. Listing sample filenames does not execute them. [Release metadata](release-types.json) · [Metadata-only reader](release-types.ps1)

The fresh guest reused the established 55-entry disabled-plugin profile. Opening the manager required neither a vehicle nor an enabled external plugin. The loader logged `Plugin Init Grid 1.3.9384.38250 by Michael Oborne`; `Plugin/PluginLoader.cs` line 308 initializes the executable's own assembly with the filename **self**. The loader also logged disabled external files. All 55 disabled selections matched before and after. Mission Planner wrote ordinary startup defaults to its temporary profile during the run. The operator pressed only Ctrl+P and sent no input to the manager itself. [Application log](release-excerpt.log) · [Profile comparison](settings-comparison.json) · [Guest input and isolation](observation.log)

The runtime was Mono with a private Xvfb display, loopback as its sole network interface, and all 1,317 original release files matching after exit. Individual sample initialization, plugin enable/disable operations and restart behavior remain untested by this observation.
